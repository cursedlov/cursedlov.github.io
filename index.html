FAQ

よくある質問
Is Hakai free? +
Yes, Hakai is completely free and open source. You can download, modify, and redistribute it as you wish.
Will it break my system? +
No. Hakai is designed to be safe and reversible. It doesn't modify core system files, only applies tweaks and optimizations that can be reverted.
Does it work on Windows 11? +
Yes, Hakai supports both Windows 10 (build 19044+) and Windows 11 (build 22631+).
Can I customize it? +
Absolutely. Hakai is built to be customizable. You can edit the Playbook, add your own tweaks, change the wallpaper, and more.
Is it safe for gaming? +
Yes. Hakai includes specific optimizations for gaming: reduced input lag, network tuning, and power plan configuration.
How do I uninstall it? +
You can reinstall Windows or use the revert option in the AME Wizard. Hakai doesn't leave permanent changes that can't be undone.
